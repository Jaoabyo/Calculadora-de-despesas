# Calculadora de orçamento

Calculadora de orçamento pessoal que recebe a renda e três despesas do usuário. O programa soma os gastos e mostra a renda, o total de despesas e o saldo final com duas casas decimais.

## Como executar

Requer Python 3 no computador. Salve os arquivos na mesma pasta e abra um terminal nela.

```sh
python orcamento.py
```

O usuário deve digitar a renda e, em seguida, informar três despesas quando o programa solicitar. Depois disso, o sistema calcula automaticamente o total das despesas e exibe o saldo final.

## Exemplo de uso

Exemplo de uso:
Renda: 3000
Primeira despesa: 1200
Segunda despesa: 450
Terceira despesa: 300

Resultado:
Renda: 3000.00
Despesas: 1950.00
Saldo: 1050.00

## Testes realizados

Conferi o programa testando com os valores 3000 de renda e despesas de 1200, 450 e 300. Também fiz as contas manualmente para confirmar que o total das despesas era 1950 e o saldo final 1050. No momento, o programa ainda não trata entradas inválidas, como letras no lugar de números.

## Limitações e próximos passos

Esta versão ainda não trata entradas inválidas e trabalha com apenas três despesas. Pretendo estudar condições, repetições, listas e funções para deixar o programa mais completo e permitir adicionar várias despesas no futuro.
